# Conversor de CEP para Latitude/Longitude

Projeto simples que contém um arquivo HTML com funcionalidade para converter CEPs em coordenadas geográficas (latitude/longitude).

## Arquivos

- [cep-geo-converter (1).html](cep-geo-converter%20(1).html) — arquivo principal com a aplicação.

## Como usar

1. Abra o arquivo `cep-geo-converter (1).html` no seu navegador (duplo-clique ou `Abrir com` -> navegador).
2. Informe o CEP desejado e use a interface para obter a conversão para latitude/longitude.

## Requisitos

- Navegador web moderno (Chrome, Edge, Firefox).
- Conexão com a internet caso a aplicação consulte uma API externa.
